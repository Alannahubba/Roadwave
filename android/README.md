# 로드웨이브 Android

Windows판과 같은 102개 기본 방송을 쓰는 개인용 Android 앱입니다. Android 8.0 이상에서 설치할 수 있습니다. 앱에 광고나 계정 가입을 추가하지 않았습니다.

## 설치와 사용

상위 폴더의 `release/Roadwave-Android.apk`를 휴대폰으로 옮겨 열면 설치할 수 있습니다. 휴대폰이 사용 중인 파일 앱에 설치 권한을 물으면 해당 앱에서만 허용하세요. APK는 개인 설치와 업데이트용으로 서명되어 있습니다.

- 채널을 누르면 재생되고, 길게 누르거나 ⋮를 누르면 즐겨찾기·숨기기 메뉴가 열립니다. 숨긴 채널은 **숨긴 채널**에서 다시 표시할 수 있습니다.
- 국가 필터는 전체 화면과 미니 모드에서 공유합니다. 이전·다음은 선택한 국가 안에서 이동하고 숨긴 채널을 건너뜁니다. 알림의 이동 버튼에도 적용됩니다.
- 휴대폰의 볼륨 버튼으로 미디어 음량을 조절합니다. **취침 타이머 · 설정**에서는 마지막 채널 자동 재생과 15·30·60·90분 취침 타이머를 설정할 수 있습니다.
- 방송이 곡 정보를 보내면 제목과 가수를 보여줍니다. 곡 정보가 없으면 **곡 인식**을 누르거나 **자동 켜짐**으로 바꾸세요. 곡을 찾으면 **YouTube Music ↗**을 탭해서 바로 검색하거나, 길게 눌러 **YouTube Music** 또는 **Spotify**를 선택할 수 있습니다.
- 화면을 잠그거나 다른 앱을 열어도 방송을 계속 들을 수 있습니다. 재생 중에는 알림이나 잠금 화면에서 이동·정지할 수 있습니다.
- **+ 추가**에 방송국 이름과 MP3·AAC·HLS 스트리밍 주소를 넣을 수 있습니다.
- 월넛 우드 무늬 테두리와 무광 버튼을 두른 황록색 LCD에 채널명·국가·곡 정보를 표시합니다. 가로 공간이 넉넉하면 재생부와 방송국 목록이 나란히 표시됩니다.
- 1~6번을 길게 눌러 방송을 저장하고 짧게 눌러 재생합니다. **BAND**는 국가를 바꿉니다. **SCAN**은 채널 연결을 최대 25초 기다리고 재생이 시작되면 6초씩 들려줍니다. 다시 누르면 현재 채널에 멈춥니다. **DISP**는 채널 정보와 곡 정보 표시를 전환합니다.

즐겨찾기, 숨긴 채널, 직접 추가한 채널, 마지막 채널 등은 각 기기에 저장됩니다. Windows와 Android가 동일한 기본 목록을 사용하며 설정 동기화는 제공하지 않습니다.

곡을 인식할 때는 방송 음성에서 만든 지문만 Shazam에 전송합니다. 마이크를 사용하거나 오디오 파일을 저장하지 않습니다. 인식을 사용하지 않을 때에도 방송에서 제공하는 곡 정보는 표시됩니다. 방송사에 따라 지역 및 네트워크 조건으로 재생 여부가 다를 수 있습니다.

## Android Auto

차량에 연결하면 미디어 앱 형태로 즐겨찾기와 국가별 채널을 열고 재생할 수 있습니다. 개인 설치 APK라 Android Auto에서 표시되지 않으면, 주차 상태에서 Android Auto의 개발자 설정에 있는 **알 수 없는 소스**를 확인하세요. 이 설정은 휴대폰의 APK 설치 권한과 별개입니다.

차량 화면의 배치와 재생 버튼은 Android Auto가 가용 공간에 맞게 그립니다. 로드웨이브는 복고풍 라디오 이미지를 재생 이미지로 제공하며, 표시 위치와 크기는 차량 화면 구성에 따라 달라집니다.

첫 탭은 **모든 채널**입니다. **국가별 채널**과 **즐겨찾기**는 상단에서 선택합니다. 로드웨이브의 전체 재생 화면에서 음표 버튼으로 곡을 인식하고, 별 버튼으로 현재 채널의 즐겨찾기를 바꾸고, 금지 표시 버튼으로 현재 채널을 숨길 수 있습니다. 가용 공간에 따라 Android Auto가 버튼을 더보기 메뉴에 배치할 수 있습니다.

휴대폰과 Android Auto는 같은 즐겨찾기와 숨긴 채널 상태를 공유합니다. 즐겨찾기에 담긴 채널을 숨겨도 즐겨찾기 자체는 유지되며, 다시 표시하면 차량 즐겨찾기에도 돌아옵니다.

재생 화면 오른쪽 위 **목록**에는 방송을 선택한 범위가 표시됩니다. **모든 채널**에서 재생하면 전체 채널을, **국가별 채널**에서 재생하면 해당 국가의 채널을 표시합니다. 숨긴 채널은 빠지며, 목록에서 다른 채널을 눌러 바로 전환할 수 있습니다.

[Google의 Android Auto 테스트 안내](https://developer.android.com/training/cars/testing#real-vehicles)

Windows에서 실제 Android Auto 화면을 테스트할 때는 Google Desktop Head Unit을 사용합니다. USB 디버깅을 허용한 휴대폰을 연결하고 Android Auto의 개발자 메뉴에서 **헤드유닛 서버 시작**을 누른 뒤, `dhu/Start-AndroidAuto.ps1`을 실행합니다. 기본값은 EV6 참고용 8:3이며, `-Screen standard-landscape`로 16:9를 선택할 수 있습니다. 이 스크립트는 프로젝트의 `build/android-auto-dhu`에 풀어 둔 Google 도구를 사용합니다.

## 빌드

Android Gradle Plugin 9.3.0, Gradle 9.5.0, JDK 17 이상, Android SDK 36을 사용합니다. Windows에서는 이 폴더의 `build.ps1`을 실행하세요. 필요한 경우 `-Gradle`, `-Java`, `-AndroidSdk`에 설치 경로를 지정할 수 있습니다. 스크립트는 한글 경로 문제를 피하기 위해 임시 빌드 폴더를 사용합니다. 개인 설치용 APK는 같은 서명 키로 빌드해야 기존 앱 위에 업데이트됩니다.

공통 `catalog.json`을 빌드 시 복사합니다. 재생과 미디어 알림은 AndroidX Media3를 사용합니다. 곡 지문의 Java 구현은 MIT 라이선스의 ShazamIO 및 shazamio-core에서 참조했으며, 라이선스는 APK에 포함됩니다.
